# 智慧家庭電器儀表板

一個使用原生 HTML、CSS 和 JavaScript 開發的智慧家庭電器儀表板，提供即時監控家電狀態與用電量分析。

## 功能特色

### 1. 家電狀態管理
- 支援多種智慧家電：冷氣、燈光、電視、冰箱、洗衣機、熱水器
- 點擊家電卡片即可切換開關狀態
- 即時顯示每個家電的耗電量
- 開啟狀態具有發光邊框效果

### 2. 用電量統計
- 提供「本週」與「本月」兩種視圖切換
- 使用 Highcharts 繪製專業柱狀圖
- 顯示總用電量與平均每日用電量

### 3. 最高用電時段分析
- 自動分析並顯示今日最高用電時段
- 具有動態脈動動畫效果
- 顯示該時段的詳細用電量

### 4. 耗電最高家電追蹤
- 即時計算並顯示當前耗電最高的家電
- 動態更新家電圖示、名稱與耗電量
- 當家電狀態改變時自動更新

### 5. 今日用電趨勢
- 使用面積圖展示 24 小時的用電趨勢
- 提供互動式提示框顯示詳細數據

### 6. 即時資訊顯示
- 顯示當前時間（每秒更新）
- 即時顯示總耗電量（根據開啟的家電計算）

## 技術規格

- **解析度**: 1920×1080
- **前端技術**: 原生 HTML5、CSS3、JavaScript (ES6+)
- **圖表庫**: Highcharts
- **設計風格**: 深色主題、毛玻璃效果、現代化 UI

## 使用方式

1. 克隆此儲存庫：
```bash
git clone https://github.com/KerryHuang/powerchart.git
```

2. 直接在瀏覽器開啟 `index.html` 檔案即可查看儀表板

3. 點擊家電卡片可切換開關狀態，並觀察各項數據的即時變化

## 設計特色

- 深色漸層背景（紫藍色調）
